# Skill feedback (runtime friction)

After a **non-routine** surprise, write one markdown file here. Do not edit the skill.

## When to write

- Something misled you or required discovery not in the skill
- Skip routine successful runs

## Filename

`YYYY-MM-DDTHHMM-<short-slug>.md`

## Body

# YYYY-MM-DD — <id> · <role> · <machine>

## Context
What you were finishing.

## What happened
Specific friction.

## Suggestion (optional)
Smallest skill change that would help. Do not apply it yourself.

## Rules

- One topic per file · no secrets · Cody moves handled notes to `resolved/`
